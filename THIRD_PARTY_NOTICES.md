# Third-party notices

pure-jeff reimplements and verifies the inference of a third-party model. This file lists the upstream works it depends on or derives from, and what is (and is not) included in this repository. pure-jeff's own code is licensed under the Apache License 2.0 ([LICENSE](LICENSE), [NOTICE](NOTICE)).

## Jeff reference implementation — MIT

- Source: https://github.com/firelex/jeff, commit `3720e7c66d73b79a6e90189f3d5b0d6ecf03ddc0`
- Copyright (c) 2026 Mathias Strasser (Jeff); Copyright (c) 2026 Denis Yarats (AutoJev, on which Jeff's training code is based)
- Full text: [runtime/licenses/jeff-source/LICENSE](runtime/licenses/jeff-source/LICENSE)
- Use in pure-jeff: the Rust runtime reproduces Jeff's decision procedure, including its prompt layout and instruction texts (`runtime/rust/src/prompt.rs`), the answer-code vocabulary, temperature scaling and option masking. Its outputs are validated against Jeff. The Python reference tools (`runtime/jeff_worker.py`, `runtime/export_jeff_reference.py`) import Jeff from a local checkout; no Jeff source file is included in this repository.

## Jeff-Qwen3.5-0.8B weights — Apache-2.0

- Source: https://huggingface.co/jeff-legacy/Jeff-Qwen3.5-0.8B (formerly `mstrasser/Jeff-Qwen3.5-0.8B`), revision `51552f39a943d62e8387c4ea5e17026a1408729f`
- Copyright 2026 Mathias Strasser. A fine-tune of Qwen3.5-0.8B; the checkpoint carries its own `LICENSE` (Apache-2.0) and `NOTICE`.
- **Not included in this repository.** `tools/fetch_model.py` downloads the pinned files and verifies their SHA-256 values (`tools/checkpoint.json`).
- Anyone who redistributes the files, including by hosting them for the web demo, must keep the checkpoint's `LICENSE` and `NOTICE` with them. `apps/web-demo/build_demo.py` copies both into the demo output.
- The model card states that the training data mixes datasets under various licences, some share-alike (CC BY-SA), and that only weights and code are released. See [docs/licensing.md](docs/licensing.md).

## Qwen3.5-0.8B — Apache-2.0

- Source: https://huggingface.co/Qwen/Qwen3.5-0.8B, by the Qwen team, Alibaba Cloud.
- The base model of the Jeff weights. pure-jeff implements its text architecture (gated DeltaNet linear attention and full attention layers) in `runtime/rust/src/backbone.rs`.

## Hugging Face Transformers — Apache-2.0

- Source: https://github.com/huggingface/transformers, version 5.17.0
- `runtime/rust/src/backbone.rs` states that its equations were checked against the Transformers Qwen3.5 implementation. The official Jeff reference runs on Transformers.

## Rust dependencies

All shipped Cargo dependencies are under permissive licenses, most of them "MIT OR Apache-2.0". [docs/license-audit.json](docs/license-audit.json) lists them per crate and target, generated by `tools/audit_licenses.py` from the committed `Cargo.lock` files:

- 138 packages; no undeclared or copyleft licenses.
- `pulp-wasm-simd-flag` 0.1.1 publishes no license text; the reviewed MIT text from its repository is kept in `runtime/licenses/`.
- `candle-nn` takes its texts from the Candle repository root.

Binaries built from this repository must carry these notices. The web demo build generates `THIRD_PARTY_LICENSES.txt` for the dependencies compiled into `engine.wasm`.

## Test data

The golden files in `tests/fixtures/` and the benchmark evidence contain prompts and output probabilities of the Jeff model for artificial inputs written for this project. They contain no model weights.

## Experimental ONNX/Tract path (development only)

These files came from KazeJudge with the ONNX/Tract experiments ([docs/tract-migration-plan.md](docs/tract-migration-plan.md)). None of them is built into the Native worker, the Wasm engine or the web demo, and the ONNX model is not included.

### Tract — MIT OR Apache-2.0

- Source: https://github.com/sonos/tract, commit `9e0cfaa9b3a9251f41f74101801dc2c937b1660a` (0.23.8), by Sonos and the Tract contributors.
- `runtime/tract/vendor/data/` is a copy of Tract's `data` crate with one local change (I64→TDim cast); the original files' hashes are in `runtime/tract/vendor/upstream.json` and the licence texts (`LICENSE`, `LICENSE-APACHE`, `LICENSE-MIT`) are kept beside it. The other Tract crates are Git dependencies of `runtime/tract`.
- The optimization experiments generate patched copies of `tract-core` into ignored directories, keeping the upstream licence files ([runtime/tract-driver-profile/NOTICE.md](runtime/tract-driver-profile/NOTICE.md)). The differences to upstream are listed in [runtime/tract/patches/](runtime/tract/patches/README.md). None of these changes has been submitted upstream; results from them are not results of upstream Tract.

### jigor ONNX exporter — Apache-2.0

- Source: https://github.com/Partysun/jigor, revision `cbd9a629f1a3d9b6829399f6f88bd3363693f9bb`, `scripts/jeff/export_onnx.py`.
- `runtime/onnx/upstream/export_onnx.py` is an unmodified copy; licence text in `runtime/onnx/upstream/LICENSE.jigor`, attribution in [runtime/onnx/upstream/NOTICE.md](runtime/onnx/upstream/NOTICE.md). Its delta-rule code derives from Hugging Face Transformers (Apache-2.0).

### Public Jeff ONNX model (graph slice) — Apache-2.0

- Source: https://huggingface.co/Zatsepin/jeff-qwen3.5-0.8b-onnx, revision `e42ca8299574aed4981d711d1c29ad66674ff4b1`.
- A small Slice reproduction extracted from its graph (no weights) is kept in the evidence under `docs/research/jeff-onnx-tract/implementation-2026-10-10/`; licence text in `runtime/onnx/upstream/LICENSE.public-model`.

### Python development tools

`runtime/onnx/requirements.lock` pins ONNX, ONNX Script, ONNX Runtime and their dependencies for the development oracle. They are installed into an ignored directory and are not distributed.
