1. モデル

入力した文章と候補は、このブラウザ内でのみ処理し、どこにも送信しません。モデル（約1.7 GB）は、ボタンを押したときだけ配信元（このサイト）から取得し、このブラウザのCache Storageに保存します。保存したモデルはいつでも削除できます。
